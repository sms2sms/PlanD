# #PlanD

OBSERVE → PARAMETRIZE → ENABLE → TEST

## Ausgangsfrage

What still works when the normal infrastructure does not?

#PlanD untersucht, worüber eine Region unter veränderten Bedingungen noch verfügen kann. Ausgangspunkt ist die Surselva (Graubünden, Schweiz).

## Vier Operationen

1. **OBSERVE** — beobachten, was vorhanden ist und unter welchen Bedingungen es verfügbar bleibt.
2. **PARAMETRIZE** — Bedingungen und Abhängigkeiten explizit machen.
3. **ENABLE** — Voraussetzungen schaffen, damit eigene Handlungsmöglichkeiten entstehen.
4. **TEST** — unter veränderten Bedingungen prüfen, was tatsächlich funktioniert.
