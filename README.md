# #PlanD

OBSERVE → PARAMETRIZE → ENABLE → TEST

## Guiding question

What still works when the normal infrastructure does not?

#PlanD investigates what a region can still access and use under changing conditions. Its starting point is the Surselva region in Graubünden, Switzerland.

## Four operations

1. OBSERVE — Identify what exists and the conditions under which it remains available.
2. PARAMETRIZE — Make conditions and dependencies explicit.
3. ENABLE — Establish the prerequisites for independent action.
4. TEST — Examine what actually works when conditions change.

## Key distinction

#AutarkieIndex does not measure what we own. It measures what we can still access and use under changing conditions.
